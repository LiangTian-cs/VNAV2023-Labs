## D1.1 光轴上球的透视投影

条件：相机光心为原点，归一化成像平面 Z=1，球心 C=(0,0,d)，半径 r，d>r+1。像素尺寸与焦距均为 1、主点为零。

图像点 (u,v) 对应射线 P(lambda)=lambda*(u,v,1)，lambda>0。代入球面方程：

    lambda²*(u²+v²+1) - 2*d*lambda + d²-r² = 0

轮廓对应射线与球相切，关于 lambda 的二次方程判别式为零：

    4*d² - 4*(u²+v²+1)*(d²-r²) = 0
    u²+v² = r²/(d²-r²)

因此轮廓为圆，圆心 (0,0)，半径 rho=r/sqrt(d²-r²)。投影填充区域满足 u²+v² <= rho²。

注意：r/d 是把球粗略看作位于固定深度的平面圆盘时得到的近似，不是球体轮廓的精确结果；d 远大于 r 时两者才接近。

## D1.2 球心不在光轴上

设 C=(a,b,c)，仍令 qvec=(u,v,1)，S=a²+b²+c²-r²。代入球面得到：

    norm(qvec)²*lambda² - 2*(C·qvec)*lambda + S = 0

相切条件：

    (a*u+b*v+c)² = S*(u²+v²+1)

写成图像上的二次曲线：

    (b²+c²-r²)*u² - 2*a*b*u*v + (a²+c²-r²)*v²
    - 2*a*c*u - 2*b*c*v + (a²+b²-r²) = 0

在球完整位于相机前方的通常条件 c>r 下，S>0，曲线判别式 B²-4*A*Ccoef = -4*S*(c²-r²)<0，因此轮廓为椭圆；光轴上的情形退化为圆这种特殊椭圆。

椭圆中心为 (a*c/(c²-r²), b*c/(c²-r²))，一般不是球心的透视投影 (a/c,b/c)。不要认为偏离光轴的球一定仍投影为以球心投影为圆心的圆。

条件边界：如果“任意位置”允许球跨越相机平面、相机位于球内等情况，不能无条件说是有限椭圆；需同时考虑二次曲线类型、正向可见射线和视野。本答案关于正常可见球体采用 c>r。

## D2.1 平行直线的消失点

三维直线 L1(lambda)=P1+lambda*D、L2(mu)=P2+mu*D，共享非零方向 D=(dx,dy,dz)。

对于 L1，归一化投影为：

    u(lambda)=(P1x+lambda*dx)/(P1z+lambda*dz)
    v(lambda)=(P1y+lambda*dy)/(P1z+lambda*dz)

若 dz!=0，取沿直线的无穷远极限，得到消失点 V=(dx/dz,dy/dz)。它与 P1、P2 无关，因此两条平行线具有同一个消失点。

更统一的齐次表示：V_h=(dx,dy,dz)，齐次坐标允许整体非零倍数。一般相机内参 K 下 V_h 与 K*D 成比例；本题 K=I。

也可验证：直线投影的齐次线坐标 l1=P1×D，有 l1·D=0；第二条线同样经过齐次点 D，说明公共消失点正是该方向点。

## D2.2 什么时候投影后仍然平行

若 dz=0，则方向平行于图像平面，消失点位于无穷远。对不经过光心、能投影为有限且不同直线的情形：

    u(lambda)=P1x/P1z + lambda*dx/P1z
    v(lambda)=P1y/P1z + lambda*dy/P1z

其二维方向与 (dx,dy) 平行，第二条线也一样，所以投影仍平行。

反向看：非重合的两条二维平行线只在无穷远相交，因此其公共方向消失点满足 dz=0。故在排除退化情形后，方向的 z 分量为零是充要条件。

退化情形必须说明：过光心的三维直线可能投影成一个点；两条空间线的投影可能重合；位于相机平面的点也没有通常的有限透视坐标。不能把这些情况当成普通二维平行线来讨论。

## 口头检查

1. 为什么球轮廓用判别式为零？因为边界射线与球相切，两个交点合并。
2. 为什么球移到光轴外会成椭圆？因为相机平面以斜向截取切锥，不再保持轴向圆截面。
3. 消失点为什么不依赖直线起点？无穷远极限由公共方向主导。
4. 消失点不存在吗？有限图像内可能没有，但射影表示下可位于无穷远。
5. 理论推导与数值验证区别？数值残差能发现实现错误，但不能代替一般证明。
