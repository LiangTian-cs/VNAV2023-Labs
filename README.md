# MIT VNAV 2023 Labs

Personal solutions and notes for MIT Visual Navigation for Autonomous Vehicles (VNAV), 2023 ROS1 version.

## Structure

- `lab1/` - Linux, Shell, Git, C++, CMake
- `lab2/` - ROS1, TF, rigid transformations
- `lab3/` - Geometric control / TESSE
- `lab4/` - Trajectory optimization
- `lab5/` - Computer vision
- `lab6/` - Two-view geometry / OpenGV
- `lab7/` - Visual odometry / GTSAM
- `lab8/` - Place recognition / object detection
- `lab9/` - SLAM / VIO
